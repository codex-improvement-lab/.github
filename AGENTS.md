# Lab organization profile repository

This directory is the independent Git repository for the public GitHub
organization profile. `profile/README.md` is a navigation surface for human
developers and agents, not evidence that any project has external users.

Describe only released products and their actual narrow jobs. Link each current
release or repository directly. Keep examples and claims labeled; do not turn
previews or internal tests into production or adoption claims. Maintain the
Lab's agent-first, human-readable direction while making quick choices possible.

Commit and push only this repository from this directory. Do not combine child
project histories or change their packages here. Follow the parent workspace
AGENTS.md and the user's existing publishing authorization.
